# Static Images Directory

Brand assets for the dashboard. They are copies from the `kwizbranding` R package
(`kwiz-R-packages/kwizbranding/inst/logos`), the single source of truth for the
Kwiz Computing Technologies logo. Replace them from there, never by hand.

- `kct-logo.svg` - the inverted-colour KCT logo, used in the navbar
  (`Kwiz Inverted Color Transparent bg.svg` in kwizbranding)
- `../favicon.ico` - the KCT favicon, same file as the company website's
- `run-app.svg` - README illustration

## Theme colours

- Primary (Teal): #1B6B5F
- Secondary (Coral): #F49B7A
- Background: #FFFFFF
- Text: #333333
